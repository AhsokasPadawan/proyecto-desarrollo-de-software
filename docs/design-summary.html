Flujo 1: Validacion de Jugada, Simulacion Reversible de Jaque y Transicion de Estado

Como interactuan ChessGame, IGameState, MoveCommand, CheckDetector e IGameObserver al invocar makeMove(from, to).

Paso 1 - Estado y Turno
Fase acepta jugadas?
Consulta currentState.canAcceptMoves() y board.getPieceAt(from).
GAME_OVER / EMPTY / WRONG_TURN
Paso 2 - Geometria
Destino en Pseudo-Legal Moves?
piece.getPseudoLegalMoves(from, boardQuery) evalua rayos, saltos y obstaculos.
ILLEGAL_MOVE
Paso 3 - Simulacion
Deja Rey en Jaque?
Ejecuta cmd.execute(), consulta CheckDetector.isKingInCheck. Si hay jaque propio llama cmd.undo().
KING_LEFT_IN_CHECK
Paso 4 - Command
Confirmar en CommandHistory
Apila MoveCommand en undoStack, limpia redoStack, alterna currentTurn.
OK - Reversible con undo()
Paso 5 - Patron State
Transicion Polimorfica
Evalua (isInCheck, hasAnyLegalMove): IN_PROGRESS, CHECK, CHECKMATE o STALEMATE/DRAW.
OK - Cero bloques switch
Paso 6 - Observer
Emision de GameSnapshot
Notifica a cada IGameObserver con GameSnapshot inmutable y retorna success:true.
OK - UI React re-renderiza

Flujo 3: Adaptador React + Tailwind en 2 Clics

  1. 1. Suscripcion: useSyncExternalStore(game.subscribe, game.getSnapshot) - React recibe GameSnapshot inmutable cuando el Core cambia.
  2. 2. Primer Clic: onSquareClick(pos) guarda selectedPos y llama game.getLegalMoves(pos) para resaltar destinos validos.
  3. 3. Segundo Clic: game.makeMove(selectedPos, targetPos). Si falla usa REJECTION_MESSAGES[res.reason]; si exito y modo IA activo dispara aiStrategy.chooseMove(game).
